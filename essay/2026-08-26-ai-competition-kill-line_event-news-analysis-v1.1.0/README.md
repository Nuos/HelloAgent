## 核心判断

“大模型开发斩杀线”在本文中是一个产业分析概念，而不是厂商或学界已经统一采用的标准术语。它指：对某类任务而言，最强且广泛可得的开放权重/免费模型形成能力底线，低价或免费推理进一步形成价格上限。收费模型若无法明显超过这一公共基线，也缺乏 SLA、合规、专有数据、工具生态、分发或工作流优势，其模型层定价权与估值溢价会被快速压缩。

这一机制具有明显的行业正外部性：开放权重可被本地部署、量化、微调和二次组合，能更广泛地扩散到 Agent、应用、研究与云基础设施中，从而降低行业早期进入门槛并加速互补生态形成。

但本文没有把“开放模型能够阻止 AI 泡沫”写成必然结论。更准确的判断是：开放模型能够压缩仅来自模型稀缺性的租金，并持续给模型能力做市场化重估；与此同时，泡沫风险仍可能迁移至 GPU、数据中心、能源、云与长期算力合同。

## 代表性主体

- OpenAI：旗舰闭源能力 + GPT-OSS 开放底座 + 分层 API 定价。
- Anthropic：闭源高端路线，通过 Sonnet/Opus 内部分层不断提高付费价值门槛。
- DeepSeek：Pro/Flash 双档开放权重路线，同时向高能力与经济档施压。
- MiniMax：将低价/开放竞争向 Agent、多模态与视频扩展。
- Freebuff：免费 Coding Agent，显示免费开始进入 Agent 执行层。
- OpenRouter：免费模型集合、`:free` 变体与免费路由，降低模型切换和试用门槛。
