# AI竞争进入“大模型斩杀线”时代：从价格战、红包补贴到开源强模型与免费Agent，行业正在用公共能力底线重估价格、壁垒与估值

## 四｜四家代表性供应商的不同站位

DeepSeek：最接近“外部斩杀线”的制造者。 2026年4月发布的V4 Preview同时提供Pro和Flash，并同步开放权重。官方把Pro定位为与顶级闭源模型竞争，把Flash定位为更快、更经济。其战略价值不是简单“便宜”，而是把强能力变成所有竞争者都必须面对的公开参照。

OpenAI：一边守住高端溢价，一边主动防守开放底座。 GPT-5.6 Sol、Terra、Luna形成闭源价格梯度；与此同时，gpt-oss-120b和20b以Apache 2.0开放权重存在。这个组合很像主动自我蚕食：宁可自己提供一个开放能力基线，也不把整个开放开发者层完全让给其他生态。这个“战略意图”属于结构性推断，不是OpenAI官方表述。

截至2026年8月26日，OpenAI官网列出的标准API价格为：GPT-5.6 Sol输入4美元/百万Token、输出20美元；Terra为2美元/12美元；Luna为0.20美元/1.20美元。价格梯度说明旗舰供应商正在明确分离“最强能力”和“规模化经济能力”，而不是让所有任务都使用最昂贵模型。

Anthropic：闭源高端路线并没有失效，但必须不断把价值线向上推。 Sonnet 5官方称其在部分Agent任务上接近Opus 4.8，当前价格为2美元/百万输入、10美元/百万输出，而Opus 4.8为5美元/25美元。Anthropic没有通过开放权重建立外部公共基线，却在自己的产品内部制造“上一代斩杀线”：更便宜的新Sonnet不断吞掉旧模型和部分Opus级工作负载。

MiniMax：把开放与低价从文本扩展到Agent、多模态和视频。 M3于2026年6月强调Coding、Agentic、1M上下文和原生多模态，并以开放权重路线进行定位；其当前模型页同时提示完整Hugging Face/GitHub开源仍在推进，因此“开放定位”和“所有权重已经完全可下载”需要区分。H3则在8月3日明确宣布开源。

MiniMax当前Token Plan页面显示，M3在512K以内上下文的促销后公开价格约为0.30美元/百万输入、1.20美元/百万输出。更重要的是，路透在8月26日报道，MiniMax 2026年上半年收入达到1.166亿美元，同比增长283.1%。这说明“低价/开放”并不天然等于“无法商业化”，关键在于是否能把低价转化为更广采用和更多场景。

## 五｜Freebuff与OpenRouter：免费开始蔓延到Agent执行层

模型价格下降之后，下一层自然被冲击的是Agent。Freebuff在2026年2月发布时把自己定义为“free coding agent”：不收订阅费、不要求信用卡，也没有做一次大任务之后突然变付费的信用额度封顶。它的核心逻辑是为不同任务选择合适的开放权重模型。Freebuff还在官方发布文中声称，过去18个月前沿模型价格下降约10倍，而付费coding工具的价格没有同步下降——这一数字属于公司自述，但它揭示了一个真实商业缝隙： 底层智能成本下降得比应用层订阅价格快。

OpenRouter则提供了另一种“免费”：免费模型集合、`:free`变体以及`openrouter/free`自动路由。用户不需要判断每个免费模型的具体供应商，路由器可以根据图像、工具调用、结构化输出等要求选择可用模型。

免费Agent + 免费模型路由，是斩杀线从“模型能力”进入“可完成任务的工作单元”的标志。 一旦一个开发者可以零订阅成本获得“模型 + Agent harness + 工具调用”的可用组合，收费产品就必须证明自己在成功率、连续性、隐私、速度、团队协作和企业治理上明显更好。

但“免费”必须读懂成本来源。OpenRouter明确提示免费模型可能有不同限速和可用性，部分免费模型还可能把输入输出用于训练；Freebuff未来的商业模式与长期免费政策也可能变化。它们提供的是 用户侧零价 ，不是整个系统没有成本。

## 六｜为什么开放竞争更利于行业早期生态

行业早期最稀缺的往往不是利润，而是 使用密度 。一个模型只有被成千上万开发者真正部署，才会快速暴露推理框架、量化、工具调用、长上下文、芯片兼容、微调、Agent稳定性等问题。开放权重把这种实验从少数厂商内部扩散到整个行业。

University of Florida 2026年的研究把这种现象建模为长期知识溢出：开放会让下游开发者更愿意采用，并通过社区改进和使用经验提高后续模型的扩散。换句话说，开放模型不只是“送掉产品”，还可以把整个互补品市场做大——推理引擎、芯片适配、云托管、Agent框架、评测工具、私有微调和行业应用都会围绕它成长。

这正是它比一次红包更有长期意义的地方。红包用完，用户可能离开；API促销结束，价格可以上调；但一个已经形成广泛部署、教程、量化版本、插件和Agent兼容性的开放模型，会形成 生态路径依赖 。

旧互联网也曾通过Linux、Apache、MySQL等开源基础设施大幅降低创业门槛。AI的不同之处是，大模型本身就是高成本核心生产资料。当这部分也开始开放，创业公司可以把资金从“重新训练一个普通模型”转向产品、数据和真实业务问题。对于行业早期，这种资源重新配置通常比重复造轮子更有效率。
