# AI竞争进入“大模型斩杀线”时代：从价格战、红包补贴到开源强模型与免费Agent，行业正在用公共能力底线重估价格、壁垒与估值

## 七｜斩杀线如何进入企业估值

资本市场真正关心的不是模型排行榜，而是 未来能够独占多少现金流 。如果开放模型不断把“昨天还稀缺的能力”变成公共底线，那么模型公司的估值就需要从“拥有某项能力”改为“拥有高于公开基线的可持续增量”。

| 估值组成 | 开放斩杀线的影响 |
| --- | --- |
| 模型能力溢价 | 最直接被压缩；公开基线越强，普通模型的稀缺性越低 |
| 用户与分发 | 反而更重要；拥有大规模入口可把任意模型转化为产品 |
| 企业SLA/合规 | 更重要；开放权重不能自动提供审计、赔偿、稳定服务和全球合规 |
| 专有数据/工作流 | 更重要；决定模型是否真正嵌入业务而非随时可替换 |
| 算力与推理基础设施 | 可能受益；价值可能从模型层上移到GPU、云、能源和托管 |
| 前沿研发能力 | 仍可获得高溢价，但必须持续领先移动中的开放基线 |

当前几家公司的估值差异非常大，而且不能机械横比。路透公开资料显示，OpenAI最近一次私募估值约8520亿美元；Anthropic在2026年5月融资后的估值达到9650亿美元；中国上市公司文件对DeepSeek一次股权交易的推算约为518亿美元，后续融资讨论又出现更高目标。它们的收入、融资阶段、地域资本市场、股权结构和业务范围都不同，因此这些数字不能直接证明谁被高估或低估。

它们真正说明的是： 资本已经给“前沿模型”本身赋予极大的期权价值。 当开放模型把能力差距压缩时，投资者会更快要求这些估值兑现为收入、利润、用户留存、企业合同和持续的技术领先。路透Breakingviews在2026年5月也明确讨论过：开放模型对高成本专有模型及其高估值构成威胁。

“斩杀线阴影区”的估值原则可以压缩成一句话： 不能再按“你有一个大模型”估值，而要按“你比最强公共基线多出来多少、这个差距能保持多久、能否兑现现金流”估值。

## 八｜它能降温泡沫，但不能保证消灭泡沫

这里需要对“能够阻止互联网泡沫式灾难”做一个重要修正。开放模型确实可以阻止一种泡沫： 把普通模型包装成稀缺前沿能力、长期维持高价格和高估值的泡沫。 因为开源权重会不断给市场做公开的“能力标记”。

但它无法自动阻止另外三种风险。第一，前沿训练和推理仍需要巨额GPU、能源和数据中心；第二，资本可以把模型层被压缩的租金转移到算力基础设施和云平台；第三，头部企业为了持续领先斩杀线，反而可能投入更大的资本开支。

旧互联网泡沫时期也有大量开源软件存在，但股票估值、网络基础设施和融资杠杆仍然可以脱离现金流。AI同样如此。2026年关于OpenAI、Anthropic和SoftBank的大额融资与算力合同已经说明，泡沫风险并不会因为模型开放而消失。更准确的说法是： 开放模型提供了一套持续的“能力按市价重估”机制，它能够减少信息不对称和技术稀缺性的虚高估值，却不能替代资本纪律。

甚至存在一个反直觉结果：当模型本身越来越便宜，需求可能急剧扩大，总算力消耗反而上升。相关经济学研究也指出，开放模型可以压低专有模型定价，却可能把更多租金推向上游算力层。因此，未来的泡沫如果出现，未必主要出现在“模型API”本身，而可能出现在数据中心、芯片、电力和长期算力合同。

## 九｜下一阶段：模型公司会被迫回答三个问题

第一个问题：你到底在斩杀线之上多少？ 如果强开放模型已经能够解决90%的常见编码、办公、搜索和推理任务，那么收费旗舰必须在剩下10%的高价值任务上证明显著优势。

第二个问题：如果模型可替换，你还有什么不能替换？ 企业客户真正难迁移的可能是数据治理、Agent状态、权限体系、审计、工作流和组织知识，而不是某个模型ID。

第三个问题：你的免费与低价能否形成生态，而不是只烧钱？ 如果开放只带来下载量，却没有形成托管、企业服务、应用入口、开发者标准或下一代模型反馈，它仍可能只是昂贵的营销。

从这个角度看，OpenAI、Anthropic、DeepSeek、MiniMax并不是在同一条线上做同一件事。OpenAI试图同时占据旗舰模型、开放底座和Agent平台；Anthropic把闭源价值集中在高可靠Agent和企业执行；DeepSeek以开放权重和成本效率持续抬高公共能力线；MiniMax则把开放和低价向多模态、Agent和视频扩散。Freebuff、OpenRouter这样的下游产品又继续把这些能力组合成免费入口。

AI竞争真正进入的新阶段，不是谁先把价格降到零，而是谁能在“公共智能越来越强”的环境里仍然创造不可替代的增量价值。 斩杀线不是终点，它是一条不断移动的海平面。海平面每上升一次，整个行业都必须重新解释自己为什么值得收费、为什么值得融资、为什么值得存在。
